Event types

approach    someone came within range (distance_cm)
hold_start  hand started gripping (force_pct)

verdict     grip rated: verdict = too_soft | nice | strong | too_hard
nudge       nobody shook yet, reminder played
timeout     reaction window ran out
goodbye     goodbye clip played
boot        device powered up
enabled / disabled   system switched on/off from this page
